PART 1: SYSTEM OVERVIEW AND BUSINESS RULES
================================================================================

1.1 CORE PURPOSE
EndoTalent is an online soccer recruitment and skill-sharing platform. It allows players (talents) or their parents to upload short technical soccer drills/skills video clips in a TikTok-style vertical video feed. Scouts and clubs browse, filter, and search these talents. If a scout wants to contact a player, they must pay an unlock fee or purchase a subscription. They can also pay to open a chat channel. All transactions pay out 90% of the fees directly to the player's (or parent's) virtual wallet.

1.2 USER ROLES
- Admin: Oversees the system, deletes users, views reported user alerts, resolves complaints, adjusts wallets directly, and applies a 10% wallet bonus.
- Scout / Club: Searches and filters talents on a directory or virtual pitch map. Can top up wallet, purchase Pack Pro subscription, pay $50.00 to unlock player contacts, pay $10.00 to unlock chat conversations, send text/voice messages, and initiate audio/video calls.
- Talent: A direct player account. Fills in age, nationality, position, height, weight, dominant foot, and bio. Uploads up to 5 videos for free, or unlimited videos if subscribed to the Pro Pack ($30.00/month). Manages wallet balances.
- Parent: An account type that acts as a legal and financial guardian. Can register and manage multiple child talent profiles. Uploads videos on behalf of children. Collects and manages financial payouts from scouts who unlock child contacts.

1.3 PRICING AND REVENUE SPLITS
- Contact Unlock Price: $50.00.
- Chat Unlock Price: $10.00.
- Talent Pro Pack: $30.00 per month (renews monthly).
- Payout Commission: 90% is credited to the talent or parent of the talent. 10% is retained by the EndoTalent platform.
- Subscription Bypass: Scouts with an active 'talent_plus' subscription plan get free, unlimited access to contact info and chats. Talents/Parents with a pro subscription can upload unlimited videos instead of the 5-video limit.

1.4 AVATAR THEMING (INAZUMA ELEVEN ANIME CHARACTERS)
If a talent user does not upload a custom profile picture, the application dynamically displays a specific anime character from the "Inazuma Eleven" series based on the player's primary position:
- GK (Goalkeeper) -> Mamoru Endou (gardien)
- CB / LB / RB (Defenders) -> Ichirouta Kazemaru (deffence)
- CDM / CM / CAM / AMF / CMD (Midfielders) -> Yuuto Kidou (milieu)
- LW / RW / ST / CF (Attackers) -> Shuuya Gouenji (Attack)

PART 4: CORE CONTROLLER LOGIC DETAILS
================================================================================

4.1 ADMINCONTROLLER
- Renders 'admin/index' page using Inertia.
- Resolves all users, reports, and wallet transactions.
- Handles wallet increments and decrements.
- Contains the 10% wallet bonus logic:
  $bonus = $user->wallet_balance * 0.10;
  Updates wallet_balance and creates WalletTransaction record of type 'bonus' and description '10% admin wallet bonus'. Prevents bonus calculation if balance is zero or negative.

4.2 CALLCONTROLLER
- Checks conversation membership.
- Ensures caller can message in the conversation (auth user is scout who unlocked or subscribed, or is talent/parent).
- Broadcasts CallStarted event (conversation_id, caller_id, caller_name, call_type) via Reverb WebSocket.
- Relays SDP signaling payloads through CallSignal event.

4.3 CHATCONTROLLER
- Lists conversations sorted by recent activity with unread counts.
- Verifies messaging eligibility.
- Processes text and voice note messages.
- Processes conversation unlock payments:
  Charges scout $10.00.
  Deducts $10.00 from Scout balance, adds 90% ($9.00) to recipient (or their parent).
  Generates wallet transactions for both.
  Sets Conversation.is_paid = true.
  Flashes success toast.

4.4 ONBOARDINGCONTROLLER
- Manages onboarding state machine.
- Direct talent setup updates TalentProfile in database.
- Parent onboarding setup creates child user:
  Creates User model with random password and email: 'talent-' . uniqid() . '@endotalent.com'.
  Saves child stats to TalentProfile table.
  Attaches relationship using parent_talent pivot table.
- Handles add-additional-children requests via `createChildTalent` on dashboard.

4.5 TALENTCONTROLLER
- Index method queries TalentProfile with 'user' relationship.
- Filters query dynamically:
  - If position param, where('position', position).
  - If dominant_foot param, where('dominant_foot', dominant_foot).
  - If gender param, whereHas('user', function($q){ $q->where('gender', gender) }).
  - If search text, search display_name, nationality, city, or country with like queries.
- Unlock method:
  Deducts $50.00 from Scout's wallet.
  Credits $45.00 (90%) to player/parent.
  Logs 'purchase_contact' and 'received_contact' in wallet_transactions.
  Creates UnlockedContact record.

4.6 VIDEOCONTROLLER
- Lists published videos with users, comments (with replies), and likes.
- In store(): Checks if user is eligible to upload (Free players have a limit of 5 videos, Pro players have unlimited uploads).
- Detects if uploader is parent and links video to chosen child profile.
- Saves raw video file to disk and dispatches `ProcessVideoJob`.

4.7 WALLETCONTROLLER
- topup(Request): Validates amount ($5 to $10,000). Updates user balance and logs transaction.
- transfer(Request): Prevents talent and parents from sending transfers. Checks scout balance, transfers money to target user via email lookup, and logs both debit and credit transactions.

PART 5: REAL-TIME BROADCASTS & JOB PROCESSING
================================================================================

5.1 BROADCAST EVENT: MessageSent
- ShouldBroadcastNow.
- Broadcasts on private channels: 'chat.{conversation_id}' and 'App.Models.User.{recipient_id}'.
- Broadcast name: 'message.sent'.
- Payload: Message object.

5.2 BROADCAST EVENT: CallStarted
- ShouldBroadcastNow.
- Broadcasts on private channels: 'chat.{conversation_id}' and 'App.Models.User.{recipient_id}'.
- Broadcast name: 'call.started'.
- Payload: conversation_id, caller_id, caller_name, call_type.

5.3 BROADCAST EVENT: CallSignal
- ShouldBroadcastNow.
- Broadcasts on private channel: 'chat.{conversation_id}'.
- Broadcast name: 'call.signal'.
- Payload: type, data, from_user_id.

5.4 QUEUE JOB: ProcessVideoJob
- Marks video status as 'processing'.
- Opens raw video file using FFMpeg from local disk.
- Runs getVideoStream()->getDimensions() to check orientation:
  If height > width, orientation = 'vertical'. Else orientation = 'cinema'.
- Transcodes video using X264 low-bitrate settings (1000 KiloBitrate) for quick streaming.
- Saves compressed MP4 file and a thumbnail frame captured at 1 second to AWS S3.
- Updates video record with the new S3 file paths, video duration, orientation, and status 'ready'.
- Deletes the local raw video file to save disk space.
